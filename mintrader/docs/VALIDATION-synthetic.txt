WHAT THIS FILE IS, AND WHAT IT IS NOT
--------------------------------------------------------------------------
This is the output of `python tools/validate.py` run on data produced by the
built-in price generator, not on observed market data.

It therefore demonstrates exactly one thing: that the whole machine runs
end to end - discovery, multi-timeframe analysis, regime classification,
tactic routing, scoring, sizing within the configured bounds, order safety,
FlowLock management, journalling, and the statistics that keep a backtest
honest - and that it produces coherent, internally consistent numbers after
spread, slippage and commission.

It says NOTHING about whether the system has a real edge. A price process we
invented cannot answer that question, and the deflated Sharpe figure above
says so explicitly.

To get a result that means something, export real M1 history from your broker
(MT5: Tools -> History Centre, or right-click a chart -> Save As) and run:

    python tools/validate.py --csv EURUSD=eurusd_m1.csv GBPUSD=gbpusd_m1.csv \
                             --calendar-csv calendar.csv

The calendar CSV comes from the bot's own archive:

    python -c "from mintel.news.calendar_store import CalendarStore; \
               CalendarStore('data/calendar.sqlite').export_csv('calendar.csv')"

Only with real data AND real calendar coverage does the report stop saying
"news_aware: False" and start being evidence rather than a smoke test.
