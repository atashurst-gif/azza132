# Teacher artwork

Put Fret's face here and the app uses it automatically (coach panel avatar), e.g. an image made in ChatGPT:

- `portrait.webp`, `portrait.png` or `portrait.jpg` — square, at least 512 × 512, head and shoulders, plain background.

Only use images you have the right to use. The 3D stage shows the teacher's fretting hand and pick; it does not need this file.
